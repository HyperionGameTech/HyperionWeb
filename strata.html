Strata

Strata is the scripting language for gameplay in Hyperion. It is statically typed, compiles to native code with LLVM, and scripts recompile live when saved.

Strata is a separate project from Hyperion: a high-performance, natively compiled language for creating games. Source at github.com/StrataLanguage/stratac.

Functions

Plain C-like functions with static types. This is a complete program.

int add(int a, int b)
{
    return a + b;
}

int main()
{
    return add(2, 3); // 5
}

Control flow

if, while, for, break, and continue all work as expected.

int factorial(int n)
{
    int result = 1;
    int i = 1;
    while (i <= n)
    {
        result = result * i;
        i = i + 1;
    }
    return result;
}

Arrays and strings

Dynamic arrays grow with array_push and report their size with .length.

extern int printf(string fmt, ...);

int main()
{
    string[] pack = { "torch", "rope" };
    array_push(pack, "rations");
    printf("carrying %u items\n", pack.length);
    return (int)pack.length; // 3
}

Talking to the engine

Handles are opaque references to engine objects. Extern functions are implemented by the engine in C++. These exact declarations ship with the engine.

handle Light;
handle EngineStats;

extern float Light_GetIntensity(Light self);
extern void Light_SetIntensity(Light self, float intensity);
extern float EngineStats_GetFps(EngineStats self);

void dim_when_slow(Light lamp, EngineStats stats)
{
    if (EngineStats_GetFps(stats) < 30.0)
    {
        Light_SetIntensity(lamp, 0.5);
    }
    else
    {
        Light_SetIntensity(lamp, 1.0);
    }
}

Boxes and optionals

For a given type you defined, say, Foo - ^Foo (note the caret) allocates a value on the heap (a "box"). Boxes are move-only, and are freed when they go out of scope. This lets us forego the need for garbage collection, runtime reference counting and manual memory management.

Foo? is an optional: it may be empty, and testing it with while (cur?) blesses it, proving to the compiler that it holds a value.

Strata does not have a "null" or "nil" keyword or a "null pointer" concept. Instead, optionals are used to represent the absence of a value.

The compiler prevents you from using an optional that may be empty, so you can't crash the game by forgetting to check. 

struct Crate
{
    int weight;
    Crate? next;
};

int main()
{
    ^Crate head = Crate { .weight = 12 };

    Crate? cur = head;
    int total = 0;
    while (cur?)
    {
        total = total + cur.weight;
        cur = cur.next;

        // You can't use cur again here.
        // You'll need another `if (cur?) { ... }` and use it in that block.
    }
    return total; // 12
}

impl

An impl block attaches functions to a handle, struct or enum type to be used as methods.

A call rewrites to the free function, with self passed as the first argument. 

handle Camera;

impl Camera
{
    extern float GetFOV(Camera self);
    extern void SetFOV(Camera self, float v);

    property float FOV { get = Camera_GetFOV; set = Camera_SetFOV; }
}

void reset_view(Camera cam)
{
    cam.SetFOV(60.0); // Camera_SetFOV(cam, 60.0)
    float fov = cam.FOV;
}

Running scripts

Scripts are plain .strata files. The editor recompiles them on save, so there is no restart or reload step.
